# /public/images

Place all locally-stored images here. Suggested files:

- `logo.png` — Xammer main logo (transparent background, SVG preferred)
- `logo-dark.png` — Dark variant of the logo
- `og-default.jpg` — Default Open Graph image (1200×630px)
- `founder.jpg` — Founder photo for FounderMessage section
- `hero-bg.jpg` — Optional hero background image
- `favicon.ico` — Already in /public root

## /partners
- `aws.svg`, `azure.svg`, `gcp.svg`, `yotta.png`, `redhat.svg`, `docker.svg`, `kubernetes.svg`, `terraform.svg`, `odoo.svg`, etc.

All images in this folder are referenced as `/images/filename.ext` in the codebase.
